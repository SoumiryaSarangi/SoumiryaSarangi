### 🛰️ UDGAM — Oil Spill Detection & Vessel Attribution from Satellite SAR

<img src="https://img.shields.io/badge/Smart%20India%20Hackathon%202026-00D9FF?style=flat-square&labelColor=0D1117" />
<img src="https://img.shields.io/badge/PyTorch%202.6-0D1117?style=flat-square&logo=pytorch&logoColor=00D9FF" />
<img src="https://img.shields.io/badge/CUDA%2012.4-0D1117?style=flat-square&logo=nvidia&logoColor=00D9FF" />
<img src="https://img.shields.io/badge/Python%203.13-0D1117?style=flat-square&logo=python&logoColor=00D9FF" />
<img src="https://img.shields.io/badge/repo-releasing%20soon-0A3D62?style=flat-square" />

A three-stage geospatial pipeline — **detect → backward drift to origin → vessel attribution**. I own Stage 1: a **gated two-network detector** where a CNN scene classifier feeds a U-Net segmenter, trained on a **2,570-scene Sentinel-1 corpus**.

| Metric | Result |
|:--|:--|
| Scene classification accuracy | **0.942** |
| Pooled oil-class IoU (sealed 450-scene holdout) | **0.757** vs 0.689 classical baseline |
| Look-alike rejection at equal IoU | **0.08 → 0.84** (the classifier gate earns its place) |
| Agreement with SkyTruth Cerulean on real incidents | median IoU **0.553** |
| Land-masked ship-contact detection | 142 → **110** contacts |

Also built the classical CV path powering the live demo — dark-spot thresholding, a 10-feature RandomForest, and a land-masked ship-contact detector — emitting **schema-validated GeoJSON** for the downstream drift and attribution stages. Zero-cross-import file-contract architecture, per-scene MAD normalization, scene-level splits, validation-only thresholds, automated schema validator.
